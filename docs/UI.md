# 界面与交互说明

统一入口为 `http://192.168.0.30:8089/`，界面全中文，资源与脚本随源码提供，无 CDN、外部字体或构建依赖。

- 主机：逐台显示真实名称、地址、连接状态、CPU、内存、磁盘和虚拟机数量。可新增、编辑、检测和解除登记；解除登记不操作虚拟机。
- 虚拟机：目标主机选择与表格一致，支持创建、生命周期、停机配置、磁盘扩容、删除确认和控制台。后台任务提交后可继续浏览，关闭弹窗不会取消已经提交的任务。
- 镜像：只展示目标宿主机允许目录内的真实模板、格式、物理容量与虚拟容量，以及磁盘目录可用空间。创建表单读取同一主机的模板、存储和网络。
- 任务：显示主机、虚拟机、执行状态与错误原因。状态会持续刷新，主机离线时明确展示错误。

创建弹窗捕获打开时的主机身份，镜像／磁盘目录保存在弹窗本地；切换主机清空页面旧资源并丢弃迟到响应。虚拟机操作按主机 ID 与 UUID 绑定，忙状态也使用两者组合。
v1.1.2 VM 列表在登录且页面可见时每 5 秒轻量刷新，不清空已有行；切换主机／页面、隐藏或退出登录会停止旧轮询，迟到响应不能覆盖当前主机。地址在实际探测时显示“探测中…”，本轮未找到则显示“未探测到”及原因，不再让运行中空地址永久显示“获取中”。平台不能探测到地址不等于 guest 网络不可用，可通过控制台确认。

cloud-init 支持自定义用户名、密码或 SSH 公钥。创建表单可选 libvirt/NAT 或桥接；NAT 使用 DHCP，disk+cloud-init+桥接可取消 DHCP 并填虚拟机 IPv4/CIDR。v1.1.1 默认联网，表单层网关和 DNS 必填（API 可只传 IP，由执行端按 profile 补齐）；匹配当前网桥 profile 时自动填充，不覆盖手填，切换网段／网桥只清除失效的自动值。清空字段后提交会提示补齐，不在提交时回填。显式勾选“仅同网段内网”可省略网关／DNS，提示无法访问其他网段或互联网。静态区在 ISO／关闭初始化／NAT 时隐藏并恢复 DHCP，不修改宿主机或已有 VM 网络。CPU／内存／磁盘变更要求关机，只增不减；原 .30 的14台 VM 已按用户后续授权解除只读限制。

控制台另开平台窗口，页面同时显示主机、VM 名称及 UUID。noVNC 从同源静态目录加载；连接通过登录会话、同源来源检查和执行端 UUID 核验，VNC 仅监听宿主机回环地址。

键盘支持 Tab、Enter 和 Escape，表格在窄屏横向滚动。所有非可信动态文本通过 textContent/DOM 节点插入。登录口令不保存在前端常量或本地存储中。

管理员顶栏“修改密码”打开当前密码、新密码、确认密码对话框。新密码12–200字符，确认不一致或当前密码错误会留在对话框；成功清空字段并返回登录页，所有会话立即失效。管理员手动修改后须自行安全保存新口令，本地交付凭据文件不会被浏览器自动更新。

可复用验收定位使用 `data-testid`：`login-*`、`nav-hosts/vms/images/tasks`、`topbar-host-select`、`vm-create-*`（包括 `vm-create-ci-isolated`）、`vm-ip-*`、`task-row-*`、`vm-console-*`、`password-*`、`btn-password`。历史与增量验收分别见 `ACCEPTANCE.md`、`ACCEPTANCE-1.1.md`、`ACCEPTANCE-1.1.1.md`、`ACCEPTANCE-1.1.2.md`。
