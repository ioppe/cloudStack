# v1.1.2 地址发现定向复核

范围限于 `ipdiscovery.py`、`vmops.py` 发现集成、前端 IP 单元格及轮询，以及新增单元用例。此轮仅一次只读复核；没有改动生产虚拟机，也没有重新审查无关架构。

发现并要求修正：

1. 扫描器找到每个目标 MAC 的首个地址就停止，且扫描器、缓存和摘要采用单地址值，导致同一 MAC 的多个真实地址丢失。应扫描受限范围并贯通去重地址列表。
2. 接收预算过小，出站／背景 ARP 帧可能消耗有效回应的接收余量。应在 3 秒时间界内保留明确的总帧上限，并容纳完整请求与回应流量；用模拟干扰后晚到回应验证。关于同一 socket 是否回投自身出站帧并未单独做内核实验，不作为实测结论。
3. Host 的墙钟不应用于发现层时间界；改用独立单调时钟，避免校时改变缓存 TTL 与限流。
4. 按当前目标清理过期／离开的缓存和排队项，丢弃移除或换接口后的在途旧结果，避免常驻进程保留历史目标。
5. 停机行应优先显示未运行状态，避免先展示被动缓存中的旧地址。

复核已确认现有网桥、网段、帧字段和目标 MAC 校验、被动源优先、NAT 排除、停机不查询 QGA 及前端主机／登录迟到隔离的结构成立。上述5项修正已落地；新增多地址、接收预算、单调时钟、目标代际／迟到结果、失败降级与移除后限流的回归用例，停机 UI 用例核验旧地址隐藏。
